# BizFlow — Small Business ERP Dashboard

> Responsive business management interface combining financial KPIs, analytics, scheduling and operational views.

## Product overview

BizFlow is a lightweight ERP concept for small businesses. It brings revenue, expenses, appointments, team information, invoices, projects and settings into one consistent workspace.

## Key capabilities

- financial dashboard and KPI cards;
- revenue and expense analytics;
- interactive charts;
- monthly calendar and appointment management;
- multi-section business workspace;
- search and navigation;
- responsive collapsible sidebar;
- mobile-first interaction model.

## Product thinking

The interface is organized around the questions a small-business owner needs to answer quickly: how is the business performing, what is scheduled, and where should attention go next. Visual hierarchy and concise KPI presentation are therefore central to the design.

## Stack

**HTML5 · CSS3 · JavaScript · Chart.js · responsive design**

## Run locally

```bash
git clone https://github.com/nestlir/bizflow-erp-system.git
cd bizflow-erp-system
```

Open `index.html` or serve the directory with a static HTTP server.
